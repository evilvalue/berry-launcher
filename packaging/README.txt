BerryTrip — сборка для Minecraft 1.21.1 (NeoForge)
Сервер: 135.181.126.167:25737
BerryUp 3.0 — лаунчер-надстройка (Java, без установщика)

=========================================================
 ШАГ 1. ПРИЗМ ИЛИ ПИНКОН
=========================================================
BerryUp не запускает Minecraft сам: ему нужен Prism Launcher
или его форк PineconeMC. Поставь один из них (это бесплатно):

  Prism Launcher: https://prismlauncher.org/download/windows/
  PineconeMC:     https://pineconemc.com/download/

Java отдельно ставить не нужно: BerryUp возьмёт её из Prism.
Если Prism только что установлен — запусти в нём любую игру
один раз, чтобы он скачал Java.

=========================================================
 ШАГ 2. РАСПАКОВКА
=========================================================
Распакуй весь архив в обычную папку, например:

  C:\BerryUp

Не запускай из Program Files и из самого ZIP-архива.
В папке должны лежать два файла:

  BerryUp.jar
  BerryUp.cmd

=========================================================
 ШАГ 3. ЗАПУСК
=========================================================
Двойной щелчок по BerryUp.cmd.

Первый запуск: лаунчер найдёт Prism, предложит «Установить сборку»,
скачает её и покажет кнопку «Играть». Дальше — просто «Играть» или
«Играть с подключением к серверу».

Если Windows покажет предупреждение о скачанном файле —
«Подробнее» → «Выполнить всё равно». Это обычная метка браузера,
файл можно проверить по SHA-256 на сайте сборки.

=========================================================
 ЧТО ЛЕЖИТ РЯДОМ
=========================================================
Обновления BerryUp качает сам в %LOCALAPPDATA%\BerryUp\update,
а BerryUp.cmd подменяет BerryUp.jar при следующем запуске.
Настройки: %APPDATA%\BerryUp. Журнал: %TEMP%\BerryUp.log.
Сборка и сохранения живут в Prism, удаление BerryUp их не трогает.
